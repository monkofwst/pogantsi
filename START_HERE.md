# PARALLAX 0.1.9: новые оси

Этот файл заменяет инструкции по осям из старого README.md.

metrics.parquet из вашего сообщения уже включён в data/metrics.parquet. Для цвета укажите существующую users_scored.parquet или users_scored.csv из того же расчёта. Гипотезы пересчитывать не нужно.

python prepare_behaviour.py data/users_scores.parquet - для получения данных в формате .csv (файл слишком большой, на гитхаб не загрузить) !!!

В папке распакованного приложения:

```bash
/home/monkofwst/codes/ds/pogantsi_final/env/bin/python prepare_behavior.py /полный/путь/users_scored.parquet
bash start_linux.sh
```

Подойдёт любой Python с duckdb. На Windows после подготовки запустите start_windows.bat. Обновите страницу Ctrl+F5.

Для других метрик: --metrics /путь/metrics.parquet. Для отдельного CSV: --output profiles.csv, затем ручной импорт. Поддерживаются папки частей Parquet.

| Ось | Формула | Смысл |
|---|---|---|
| X | social_coverage | Доля перелётов с попутчиками |
| Y | pair_n / (n − 1) при n > 1; 0 при n = 1 | Связность последовательных поездок |
| Z | 1 − 1 / month_burst | Месячный всплеск на шкале 0–1 |

Например, month_burst=1 даёт Z=0, 2 даёт 0.5, 5 даёт 0.8. Исходные значения сохраняются в raw_social_coverage, raw_pair_n, raw_segments, raw_month_burst. Эти оси описывают поведение и не являются исходными G2/G3/G4. Цвет, рейтинг и фильтр используют исходный target без пересчёта. Флаги G2/G3/G4 сохранены в отдельном режиме.

Экспорт сохраняет все строки scores. Пустые показатели остаются пустыми. Профили без полных координат не рисуются; количество указано при экспорте и в разделе «Данные». Слева показаны входные профили, сверху — видимые. Несовместимые ID останавливают экспорт.

Счётчик позиций учитывает фильтр и режим. При выборе точки справа доступны первые 100 профилей с такими координатами; все ID доступны через рейтинг. Совпадения остаются возможными, случайное смещение не применяется.

Старый CSV вкладов поддерживается для сравнения и сохраняет прежнюю разреженную геометрию. Для новых осей используйте prepare_behavior.py. Встроенный passengers.csv является синтетическим демо; встроенные перелёты связаны только с демонстрационными ID.
